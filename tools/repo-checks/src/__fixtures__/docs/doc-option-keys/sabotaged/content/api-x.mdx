# `@nexusdi/x`

## `launch`

The crew and the countdown are both optional; `const crew = 4` sets neither.

```ts twoslash
import { launch } from '@nexusdi/x';
launch('Meridian', { crew: 4 });
// ---cut---
// @errors: 2304
launch('Meridian', { countdown: nope });
```

## `defineShip`

```ts twoslash
import { defineShip } from '@nexusdi/x';

defineShip('frigate');
```

## `Dock`

```ts twoslash
import { Dock } from '@nexusdi/x';

const layout = { bay: 3 };
new Dock().open(layout);
```

## `LaunchOptions`

`crew` and `countdown` are both optional.

## `ShipDefinition`

A ship, as defineShip() returns it.

## `refit`

```ts twoslash
import { refit } from '@nexusdi/x';

refit({ crew: 2, countdown: false });
```

## `Panel`

```tsx twoslash
import { Panel, type PanelProps } from '@nexusdi/x';

declare const saved: PanelProps;
export const panel = <Panel size={1} />;
saved.label;
```

## `PanelProps`

`size` is required and `label` is optional.

## `Listener`

A listener hears each signal.

## `moor`

Each berth holds a bay and a crew, and `const crew = 4` sets neither.

```ts twoslash
import { moor } from '@nexusdi/x';

moor({ berths: ['spare'] });
```

## `MoorOptions`

Each of `berths` is a name or `{ bay: 1, crew?: 2 }`.

## `grow`

```ts twoslash
import { grow } from '@nexusdi/x';

grow({ leaf: 'oak', branches: [{ leaf: 'ash' }] });
```

## `BranchOptions`

`leaf` names the branch, and `branches` holds more of them.

## `deep`

```ts twoslash
import { deep } from '@nexusdi/x';

deep({ a: { b: { c: { d: {} } } } });
```
