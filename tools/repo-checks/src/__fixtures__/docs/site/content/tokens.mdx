# Tokens

A token names what a provider supplies. The `Token` class takes a description.

## A class is its own token

<Notice kind="note">A class token needs no description.</Notice>

```ts file=libs/core/README.md region=class-token
```

## Two tokens with one description stay distinct

const a = new Token<NavCharts>('NavCharts');
