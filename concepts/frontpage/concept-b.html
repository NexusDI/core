Wiring mistakes fail CI before a user hits them.

NexusDI is dependency injection for TypeScript. It builds your app from modules and checks the whole graph before anything runs. Pull a conduit on the ship below and see.

Get started GitHub
$ npm i @nexusdi/core@next
0.4.0-rc.00.4 is a release candidate on the npm next tag.
preflight.ts 
import { Nexus } from '@nexusdi/core';
import { errors } from '@nexusdi/errors';
import { Meridian } from './meridian.js';

Nexus.check(Meridian, { plugins: [errors()] }); // CI runs this
console.log('pre-flight ok');
