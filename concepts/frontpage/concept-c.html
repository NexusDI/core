Wiring mistakes fail CI before a user hits them.

NexusDI is a typed dependency injection library for TypeScript, with modules, async startup and a pre-flight check for your wiring. Unplug a conduit below and see.

Get started → GitHub
$ npm i @nexusdi/core@next
0.4.0-rc.0. 0.4 is a release candidate on the npm next tag.

  • section = module
  • system = provider
  • conduit = dependency
  • hatch = export

Pre-flightNexus.check

import { Nexus } from '@nexusdi/core';
import { errors } from '@nexusdi/errors';
import { Meridian } from './meridian.js';

Nexus.check(Meridian, { plugins: [errors()] }); // CI runs this
console.log('pre-flight ok');
