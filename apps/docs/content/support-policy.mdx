# 0.3 Support Policy

With the release of NexusDI 0.4, the focus of the maintainers shifts to the new static-validation architecture. However, we provide a transition period for users who cannot immediately upgrade.

## Support During the RC Phase

Until 0.4.0 final is released, the `latest` tag on npm continues to point to the 0.3.x line. Any critical fixes for 0.3 during this period are released as patches under the `latest` tag.

## Support After 0.4.0 Final

Once 0.4.0 is officially released, the 0.3 line moves to a dedicated maintenance branch.

- **Fix Scope:** The 0.3 branch receives fixes only for security vulnerabilities and critical defects that cause the program to crash or lose data.
- **Installation:** You can install the newest 0.3 patch using the `release-0.3` dist-tag:
  ```bash
  npm install @nexusdi/core@release-0.3
  ```

## End of Life (EOL)

Support for the 0.3 line ends six months after the release of 0.4.0 final, or when 0.5.0 is released—whichever comes first.

After this date, the 0.3 line receives no further updates, and the 0.3 documentation is archived. We strongly recommend upgrading to 0.4 before this deadline to ensure your project remains secure and compatible with modern TypeScript versions.
