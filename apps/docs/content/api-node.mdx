# `@nexusdi/node`

A Node server needs each request's scope wherever the request's code runs, without passing it through every call. `@nexusdi/node` holds the current [NexusDI scope](/scopes/) in one `AsyncLocalStorage` per `nodeScopes()` call. `nodeScopes()` returns a `NodeScopes` object with two methods: `run(scope, fn)` makes `scope` the current scope for `fn` and everything `fn` awaits, and `current()` returns that scope from any code inside the run.
