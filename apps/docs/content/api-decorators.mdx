# `@nexusdi/decorators`

A class can carry its own provider definition, with no `provide()` call beside it. `@nexusdi/decorators` exports standard (TC39) decorators that record the definition on the class. `@Injectable()` records the `deps` and `lifetime` that `provide()` would take, so the bare class works in `providers`, and `@Inject()` on an `accessor` field records a property injection, which the container sets after the constructor returns and before `onInit`. `@Module()` makes the class a module the way `defineModule()` does, named after the class; a configurable module, one with `forRoot()`, still uses `defineModule()`. With `experimentalDecorators` set in `tsconfig.json`, each decorator throws `LegacyDecoratorsError` when it runs, and such a project registers its classes with `provide()` and `defineModule()`.
