# `@nexusdi/core`

An app declares its object graph as a tree of modules, and `@nexusdi/core` checks that tree before it builds anything. `Nexus.create(root)` compiles the tree and checks every provider, import and export. When the graph has faults, the promise rejects with one `BlueprintError` that lists each of them. Core writes each error a container raises as one line with a link to the code's page; `defineModule()` and `new Token()` throw their own full text, because no container exists yet. The `@nexusdi/core/text` entry holds core's full error text, which `@nexusdi/errors` reads. The error classes are listed on [Error codes](/api-errors/), and each code has a page of its own. Each export has one entry below, with what the package's tests state about it.

## `CreateOptions`

<!-- reference @nexusdi/core#CreateOptions -->

Plugins run in the order the `plugins` array lists them, with the exceptions [Plugin Execution Order](/plugins/#plugin-execution-order) lists. The first-party plugins are `errors()` from `@nexusdi/errors`, `devtools()`, `trace()` and `profile()` from `@nexusdi/devtools`, `interceptors()` from `@nexusdi/interceptors`, `federation()` from `@nexusdi/federation` and `react()` from `@nexusdi/react`. `createTestingContainer` from `@nexusdi/testing` puts its own plugin ahead of the caller's.
