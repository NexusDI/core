# Visualizing Your Dependency Graph

Understanding the architecture of a large application is easier when you can see it. The `@nexusdi/cli` package provides a command-line tool that analyzes your root module and draws the resulting dependency graph.

## Installation

To use the graph tool, install the CLI and the devtools plugin as development dependencies:

```bash
npm install -D @nexusdi/cli@next @nexusdi/devtools@next
```

## Drawing the Graph

The `nexusdi graph` command takes an entry point (the file defining your root module) and optionally a specific export.

```bash
npx nexusdi graph src/meridian.module.ts#Meridian
```

The command uses `Nexus.check` to validate the graph without instantiating any classes, making it safe to run in any environment.

### Export Formats and Views

You can customize the output and the level of detail:

- **Formats:** Use `-f` or `--format` to choose between `mermaid` (default), `dot`, `json`, `svg`, or `png`.
- **Views:** Use `--view modules` to see the high-level module import graph instead of the individual providers.

```bash
npx nexusdi graph src/meridian.module.ts#Meridian -o graph.svg --view modules
```

## Advanced Analysis

### Simulating Dynamic Loads

If your app uses `ship.load()` to add modules at runtime, you can simulate this in the CLI using the `--load` flag:

```bash
npx nexusdi graph src/meridian.module.ts#Meridian --load src/science.module.ts#Science
```

### Including Plugins

If you use plugins that add modules or change the graph, you can pass them via the `--plugins` flag:

```bash
npx nexusdi graph src/meridian.module.ts#Meridian --plugins src/plugins.ts#plugins
```

## CI/CD Integration

The `nexusdi graph` command is ideal for CI pipelines. It exits with code `0` if the graph is valid and code `1` if there are wiring mistakes. By adding this to your pipeline, you can prevent broken dependency graphs from ever being merged into your main branch.

```bash
# Fail the build if the graph is invalid
npx nexusdi graph src/meridian.module.ts#Meridian -f json -o graph.json
```
