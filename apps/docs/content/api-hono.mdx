# `@nexusdi/hono`

A request-scoped service needs one scope per request, disposed when the response is done. A Hono handler that streams keeps writing after `next()` returns, so a scope disposed there is gone while the stream still reads it. `nexus(ship)` returns a `NexusHono`: `di.middleware` gives each request a scope handle, and the first `di.inject` handler creates the scope and resolves its typed deps from it. The scope is disposed once, when the response body ends, errors or is cancelled, or when the request's signal aborts. A NexusDI error in a handler reaches Hono as a `NexusHttpError` with a 500 or 503 status. Each export has one entry below, with what the package's tests state about it.
