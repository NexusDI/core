# `@nexusdi/react-router`

A request-scoped service needs one scope per request, disposed when the response is done. React Router finishes the middleware chain before the server writes the body, and deferred data keeps streaming after it, so a scope disposed when the middleware returns is gone while a deferred value still reads it. `nexus(ship)` returns a `NexusRouter`: `di.middleware` in the root route's `middleware` export puts a scope handle on the router context under `NEXUS_SCOPE`, and the first `di.inject` loader or action creates the scope, which loaders that run in parallel share. The scope is disposed once, when the streamed body ends, errors or is cancelled, or when the request's signal aborts. A test puts `existingScope(scope)` under `NEXUS_SCOPE` and calls a loader directly. Each export has one entry below, with what the package's tests state about it.
