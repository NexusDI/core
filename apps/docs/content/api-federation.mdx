# `@nexusdi/federation`

Two packages that share an interface need the same token, and two installed copies of one contracts package make two `Token` objects. `@nexusdi/federation` binds them by key. `defineContract({ key, version })` returns a `Contract` whose `token(name)` and `multi(name)` make tokens keyed `<key>/<name>` and marked with the contract's version. The `federation()` plugin binds contract tokens by key across copies through core's `tokenKey` hook. A provider's contract version satisfies a dependent's when the majors match and the provider is not older. A newer minor counts from major 1 on, a newer patch counts at `0.0.x` too, and a prerelease tag is not compared. When it does not satisfy, `Nexus.create()` and `ship.load()` reject, and `Nexus.check` throws, with a `BlueprintError` whose `errors` list holds a `ContractVersionError`. `federationText` from `@nexusdi/federation/text` words those errors for `@nexusdi/errors`. Each export has one entry below, with what the package's tests state about it.
