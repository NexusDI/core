# NEXUS_INTERCEPTOR_INVALID

`@nexusdi/interceptors` raises `NEXUS_INTERCEPTOR_INVALID` for a fault in how interceptors are set up or called, and the error's `reason` field names the rule the fault breaks. The same code reaches the program in four ways, and the table under [Fix `NEXUS_INTERCEPTOR_INVALID`](#fix-nexus_interceptor_invalid) gives the way for each reason:

- Compile. The plugin's check finds the fault with the graph's other errors, and `Nexus.create` and `ship.load()` reject and `Nexus.check` throws [NEXUS_BLUEPRINT_INVALID](/errors/NEXUS_BLUEPRINT_INVALID/), whose `errors` list holds one `InterceptorError` for each fault. The check runs before any constructor does.
- Class definition. `@UseInterceptors` throws the error bare while the class is defined, which ends the import of the module that declares the class. No container exists yet, so no container wraps it.
- Build. A provider's constructor or factory throws while `Nexus.create` builds the container, so `create` rejects with [NEXUS_PROVIDER_FAILED](/errors/NEXUS_PROVIDER_FAILED/) and the `InterceptorError` is its `cause`. A fault in the `bindings` option nests one level deeper, and so does a `bad-target` fault for a provider whose instance is a frozen function with an intercepted own method: the `cause` of the provider failure is [NEXUS_PLUGIN_FAILED](/errors/NEXUS_PLUGIN_FAILED/), and the `InterceptorError` is that error's `cause`. `Nexus.check` builds nothing, so it never sees these.
- Call. An intercepted method throws the error to its caller, or returns a rejected promise when the method is declared `async`. A call made from an `onInit` hook fails the provider that owns the hook, so `create` rejects with `NEXUS_PROVIDER_FAILED` and the `InterceptorError` is its `cause`.

## Reproduce `NEXUS_INTERCEPTOR_INVALID`

`interceptors()` reports `NEXUS_INTERCEPTOR_INVALID` with `reason` set to `options` when `register` holds the same interceptor token twice. Without a text pack, the message is one line that starts with the code and ends with the address of this page.

Try it: run `npm install @nexusdi/core@next @nexusdi/interceptors@next`, save the region as `invalid.ts` and run `npx tsx invalid.ts`. It prints the one-line message: `[NEXUS_INTERCEPTOR_INVALID] reason=options token=Audit detail=register-twice.` and the address of this page. Delete one `interceptor(AUDIT, { useClass: AuditInterceptor }),` entry from the `register` list and run it again. The container builds, and the region prints `undefined` because there is no error to read. Put the entry back and the message returns.

## Fix `NEXUS_INTERCEPTOR_INVALID`

`NEXUS_INTERCEPTOR_INVALID` goes away when the declaration follows the rule its `reason` names:

| `reason`            | The fault and its fix                                                                                                                                                                                                                                                                                                                                                 | How it arrives                                   |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| `options`           | An `interceptors()` option has the wrong shape. `detail[0]` names the rule, such as `register-empty`, `register-twice`, `global-entry` or `exempt-entry`, and `detail[1]` the value received.                                                                                                                                                                         | Compile                                          |
| `declaration`       | A class's `static interceptors` is not `{ class?, methods? }`. `detail[0]` is the key at fault. Use only those two keys, each holding a list of tokens.                                                                                                                                                                                                               | Compile                                          |
| `declaration`       | A `@UseInterceptors` argument is not a token. `detail[0]` describes the value received. Pass the token.                                                                                                                                                                                                                                                               | Class definition                                 |
| `unknown-method`    | A `static interceptors` method list names a method that is not on the class's prototype chain, such as an arrow field. Correct the name, or declare the field as a method.                                                                                                                                                                                            | Compile                                          |
| `unknown-method`    | A `bindings` entry names a method that the instance its provider built lacks. Correct the name in `bindings`.                                                                                                                                                                                                                                                         | Build, as the `cause` of `NEXUS_PLUGIN_FAILED`   |
| `two-forms`         | A class uses both `static interceptors` and `@UseInterceptors`. Keep one form.                                                                                                                                                                                                                                                                                        | Compile                                          |
| `private-method`    | `@UseInterceptors` decorates a private method, and `method` holds its name, such as `#reload`. Decorate a public method.                                                                                                                                                                                                                                              | Class definition                                 |
| `static-method`     | `@UseInterceptors` decorates a static method. Decorate an instance method.                                                                                                                                                                                                                                                                                            | Class definition                                 |
| `bad-target`        | `@UseInterceptors` decorates a getter, a setter, a field or an accessor, and `detail[0]` names the kind. It can also decorate `onInit` or `then`, which are never intercepted. At build, a provider's instance is a frozen function with an intercepted own method, and `method` names it. Decorate a public instance method, or provide an object or class instance. | Class definition, or Build                       |
| `legacy-decorators` | The program runs under `experimentalDecorators`, which calls a standard decorator the legacy way. Remove the setting, or declare the interceptors with `static interceptors`.                                                                                                                                                                                         | Class definition                                 |
| `no-intercept`      | A registered interceptor has no `intercept(call, next)` method, and `token` names it. Add the method.                                                                                                                                                                                                                                                                 | Build, as the `cause` of `NEXUS_PROVIDER_FAILED` |
| `bad-next`          | An interceptor called `next()` with an argument that is not an array. Pass the new argument list as an array, or call `next()` with no argument.                                                                                                                                                                                                                      | Call                                             |
| `unexempted-dep`    | With `global` entries, an interceptor depends on a service that `exempt` does not list. `detail` holds the providers the entries would skip. Add the service to `exempt`.                                                                                                                                                                                             | Compile                                          |
| `unused-exempt`     | With `global` entries, `exempt` lists a service that no interceptor depends on directly. `detail` names the exempt services that already cover it. Remove it from `exempt`.                                                                                                                                                                                           | Compile                                          |
| `self-intercept`    | A class list, on the class or in a binding, names an interceptor on a service that the interceptor depends on, so the interceptor would run inside itself. List it only on methods the interceptor never calls.                                                                                                                                                       | Compile                                          |


The fix region differs from the reproduce region in the `register` list, which names `AUDIT` once, and in what follows: it calls `output()` on the container it keeps and prints what the interceptor saw.

Try it: save the region as `fixed.ts` and run `npx tsx fixed.ts`. It prints `1.21` and `[ 'output' ]`. ## Fields of `InterceptorError`

- `code`: `'NEXUS_INTERCEPTOR_INVALID'`.
- `reason`: the rule the fault breaks, one of the reasons in the table above.
- `token`: the name of the token the fault is about, or `null`. It is the interceptor for `register-twice`, `no-intercept`, `bad-next` and `self-intercept`, and the binding's token for a malformed binding. For `unexempted-dep` it is the interceptor that depends on the service.
- `target`: the class or provider the fault is on, or `null`. For `unexempted-dep` it is the service, and for `unused-exempt` the exempt token.
- `method`: the method name, or `null`.
- `state`: `null` for this code.
- `detail`: a list of strings, empty when the fault names nothing else. It holds the rule and the value received for `options`, the key at fault for a `static interceptors` declaration, the value received for a `@UseInterceptors` argument, the kind for `bad-target` on a getter, setter, field or accessor, and the provider names for `unexempted-dep` and `unused-exempt`.
