# NEXUS_REACT_SECTION_CONFLICT

`SectionBoundary` from `@nexusdi/react` loads each `lazySection` into the container once per section name, and keeps the module object that name loaded. It fails with `NEXUS_REACT_SECTION_CONFLICT` when a second module arrives under a name it knows. A module with a different `name` means two sections share one section name, in every build. A module with the same `name` in production means two builds of one section are in the page. In development, an edit to a section's module file reloads the page once. The conflict error appears when a second copy is still present right after that reload, or when a second edit of that module comes within 10 seconds of the reload.
