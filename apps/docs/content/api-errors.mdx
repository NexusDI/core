# Error codes

Every NexusDI error carries a stable `code`. When the app registers no text pack for an error, its message is one line of fields that ends with a link to that code's page, `https://nexus.js.org/errors/<CODE>`. Each page reproduces the error and gives the fix, with the full text. This table lists the codes of every first-party package, `@nexusdi/core` first in the order of its `NexusErrorByCode` interface.

`isNexusError(error, code)` from `@nexusdi/core` checks a code and narrows the error to its class. A package that adds codes declares them in `NexusErrorByCode`, and [How do I write a NexusDI plugin?](/write-a-plugin/) shows how.

A row that says "found inside `NEXUS_BLUEPRINT_INVALID`" names a code that arrives only in the `errors` list of that error. Other rows give the way the code arrives.

| Code                                                                    | Package                 | Class                     | Raised when                                                                                                                                                                                                                                                                                  |
| ----------------------------------------------------------------------- | ----------------------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`NEXUS_BLUEPRINT_INVALID`](/errors/NEXUS_BLUEPRINT_INVALID/)           | `@nexusdi/core`         | `BlueprintError`          | `Nexus.create`, `Nexus.check`, `validate()` or `load()` found errors in the module graph; `errors` lists each one                                                                                                                                                                            |
| [`NEXUS_MISSING_PROVIDER`](/errors/NEXUS_MISSING_PROVIDER/)             | `@nexusdi/core`         | `MissingProviderError`    | a provider depends on a token that no module visible to it provides; `get()` and `resolve()` throw it bare for a token no module provides, and `Nexus.create` and `validate()` report it inside `NEXUS_BLUEPRINT_INVALID`                                                                    |
| [`NEXUS_AMBIGUOUS_PROVIDER`](/errors/NEXUS_AMBIGUOUS_PROVIDER/)         | `@nexusdi/core`         | `AmbiguousProviderError`  | a module imports two or more modules that each export their own provider of one token; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                |
| [`NEXUS_DUPLICATE_PROVIDER`](/errors/NEXUS_DUPLICATE_PROVIDER/)         | `@nexusdi/core`         | `DuplicateProviderError`  | one module lists two providers for the same token; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                                    |
| [`NEXUS_INVALID_EXPORT`](/errors/NEXUS_INVALID_EXPORT/)                 | `@nexusdi/core`         | `InvalidExportError`      | a module exports a token it cannot see through its providers or imports, or a module it does not import; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                              |
| [`NEXUS_INVALID_PROVIDER`](/errors/NEXUS_INVALID_PROVIDER/)             | `@nexusdi/core`         | `InvalidProviderError`    | an entry in a module's `providers` is malformed; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                                      |
| [`NEXUS_INVALID_TOKEN`](/errors/NEXUS_INVALID_TOKEN/)                   | `@nexusdi/core`         | `InvalidTokenError`       | a value used as a token is no class and no token, or a `Token` has no description; `new Token('')`, `get()` and `resolve()` throw it bare, and `Nexus.create` and `validate()` report it inside `NEXUS_BLUEPRINT_INVALID`                                                                    |
| [`NEXUS_INVALID_MODULE`](/errors/NEXUS_INVALID_MODULE/)                 | `@nexusdi/core`         | `InvalidModuleError`      | a value used as a module is no `defineModule()` definition and no `@Module` class; `load()`, `defineModule()` and the `module` option of `get()` throw it bare, and `Nexus.create` reports an `imports` entry inside `NEXUS_BLUEPRINT_INVALID`                                               |
| [`NEXUS_MISSING_DEPS`](/errors/NEXUS_MISSING_DEPS/)                     | `@nexusdi/core`         | `MissingDepsError`        | a class with constructor parameters is bound without a `deps` list; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                   |
| [`NEXUS_CIRCULAR_DEPENDENCY`](/errors/NEXUS_CIRCULAR_DEPENDENCY/)       | `@nexusdi/core`         | `CircularDependencyError` | providers depend on each other in a cycle with no `lazy()` edge; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                      |
| [`NEXUS_LIFETIME_VIOLATION`](/errors/NEXUS_LIFETIME_VIOLATION/)         | `@nexusdi/core`         | `LifetimeError`           | a singleton depends on a scoped provider or on `REQUEST`; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                             |
| [`NEXUS_MODULE_IMPORT_CYCLE`](/errors/NEXUS_MODULE_IMPORT_CYCLE/)       | `@nexusdi/core`         | `ModuleImportCycleError`  | modules import each other in a loop; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                                                  |
| [`NEXUS_MODULE_OPTIONS_MISSING`](/errors/NEXUS_MODULE_OPTIONS_MISSING/) | `@nexusdi/core`         | `ModuleOptionsError`      | a configurable module is imported without `forRoot()` or `forRootAsync()`; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                            |
| [`NEXUS_LOAD_GLOBAL_MODULE`](/errors/NEXUS_LOAD_GLOBAL_MODULE/)         | `@nexusdi/core`         | `LoadError`               | `load()` received a global module, or a module that imports a global module the graph lacks                                                                                                                                                                                                  |
| [`NEXUS_INVALID_MODULE_OPTIONS`](/errors/NEXUS_INVALID_MODULE_OPTIONS/) | `@nexusdi/core`         | `ModuleOptionsError`      | a configurable module's options fail its `schema`; the `cause` of `NEXUS_PROVIDER_FAILED`                                                                                                                                                                                                    |
| [`NEXUS_PROVIDER_FAILED`](/errors/NEXUS_PROVIDER_FAILED/)               | `@nexusdi/core`         | `ProviderError`           | a constructor, a factory, `onInit` or options validation threw while the container built a provider; `cause` holds the error                                                                                                                                                                 |
| [`NEXUS_NOT_READY`](/errors/NEXUS_NOT_READY/)                           | `@nexusdi/core`         | `NotReadyError`           | a `lazy()` thunk ran before its target was ready                                                                                                                                                                                                                                             |
| [`NEXUS_ASYNC_TRANSIENT`](/errors/NEXUS_ASYNC_TRANSIENT/)               | `@nexusdi/core`         | `AsyncTransientError`     | a transient factory returned a promise when the container built it                                                                                                                                                                                                                           |
| [`NEXUS_LAZY_ASYNC`](/errors/NEXUS_LAZY_ASYNC/)                         | `@nexusdi/core`         | `LazyAsyncError`          | an `eager: false` provider, or its `onInit`, returned a promise at its first build                                                                                                                                                                                                           |
| [`NEXUS_NOT_VISIBLE`](/errors/NEXUS_NOT_VISIBLE/)                       | `@nexusdi/core`         | `NotVisibleError`         | a lookup names a token that some module provides and the looking module cannot see                                                                                                                                                                                                           |
| [`NEXUS_SCOPE_REQUIRED`](/errors/NEXUS_SCOPE_REQUIRED/)                 | `@nexusdi/core`         | `ScopeRequiredError`      | a scoped provider or `REQUEST` was resolved from the root container                                                                                                                                                                                                                          |
| [`NEXUS_REQUEST_MISSING`](/errors/NEXUS_REQUEST_MISSING/)               | `@nexusdi/core`         | `RequestMissingError`     | `createScope()` received no request while scoped providers depend on `REQUEST`                                                                                                                                                                                                               |
| [`NEXUS_LOADED_AFTER_SCOPE`](/errors/NEXUS_LOADED_AFTER_SCOPE/)         | `@nexusdi/core`         | `LoadedAfterScopeError`   | a scope was asked for a token from a module that `load()` added after the scope was created                                                                                                                                                                                                  |
| [`NEXUS_DISPOSED`](/errors/NEXUS_DISPOSED/)                             | `@nexusdi/core`         | `DisposedError`           | a container or scope, or a `lazy()` thunk, was used after disposal started                                                                                                                                                                                                                   |
| [`NEXUS_PLUGIN_INVALID`](/errors/NEXUS_PLUGIN_INVALID/)                 | `@nexusdi/core`         | `PluginError`             | a plugin passed to `Nexus.create` or `Nexus.check` is malformed; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                      |
| [`NEXUS_PLUGIN_VERSION`](/errors/NEXUS_PLUGIN_VERSION/)                 | `@nexusdi/core`         | `PluginError`             | a plugin declares a plugin API version this core does not support; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                    |
| [`NEXUS_PLUGIN_CONFLICT`](/errors/NEXUS_PLUGIN_CONFLICT/)               | `@nexusdi/core`         | `PluginError`             | two plugins rewrite the same module or provider; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                                      |
| [`NEXUS_PLUGIN_FAILED`](/errors/NEXUS_PLUGIN_FAILED/)                   | `@nexusdi/core`         | `PluginError`             | a plugin hook threw or returned a value of the wrong type; `cause` holds the error. A `setup` hook and a `tokenKey` hook met in a lookup throw it bare, a `compile` hook reports it inside `NEXUS_BLUEPRINT_INVALID`, and a `construct` hook makes it the `cause` of `NEXUS_PROVIDER_FAILED` |
| [`NEXUS_LEGACY_DECORATORS`](/errors/NEXUS_LEGACY_DECORATORS/)           | `@nexusdi/decorators`   | `LegacyDecoratorsError`   | a decorator ran under `experimentalDecorators`                                                                                                                                                                                                                                               |
| [`NEXUS_DEVTOOLS_UNREGISTERED`](/errors/NEXUS_DEVTOOLS_UNREGISTERED/)   | `@nexusdi/devtools`     | `DevtoolsError`           | `graph()` read a container created without `devtools()`                                                                                                                                                                                                                                      |
| [`NEXUS_DEVTOOLS_GRAPH_INVALID`](/errors/NEXUS_DEVTOOLS_GRAPH_INVALID/) | `@nexusdi/devtools`     | `DevtoolsError`           | `parseGraph()` received a value that is not a `NexusGraph`; `path` names the first field that failed                                                                                                                                                                                         |
| [`NEXUS_CONTRACT_VERSION`](/errors/NEXUS_CONTRACT_VERSION/)             | `@nexusdi/federation`   | `ContractVersionError`    | a dependent needs a contract version its provider does not satisfy; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                   |
| [`NEXUS_INTERCEPTOR_INVALID`](/errors/NEXUS_INTERCEPTOR_INVALID/)       | `@nexusdi/interceptors` | `InterceptorError`        | an interceptor option, a declaration, a call or an interceptor is malformed; `reason` names the rule. The compile reports it inside `NEXUS_BLUEPRINT_INVALID`, `@UseInterceptors` throws it bare, and a build fault makes it the `cause` of `NEXUS_PROVIDER_FAILED`                          |
| [`NEXUS_INTERCEPTOR_MISSING`](/errors/NEXUS_INTERCEPTOR_MISSING/)       | `@nexusdi/interceptors` | `InterceptorError`        | a declaration names an interceptor that `register` does not list; found at compile inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                          |
| [`NEXUS_INTERCEPTOR_LIFETIME`](/errors/NEXUS_INTERCEPTOR_LIFETIME/)     | `@nexusdi/interceptors` | `InterceptorError`        | an interceptor is registered as scoped or transient; found at compile inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                                       |
| [`NEXUS_INTERCEPTOR_NOT_READY`](/errors/NEXUS_INTERCEPTOR_NOT_READY/)   | `@nexusdi/interceptors` | `InterceptorError`        | an intercepted method was called before the interceptors were built or after disposal                                                                                                                                                                                                        |
| [`NEXUS_INTERCEPTORS_SHARED`](/errors/NEXUS_INTERCEPTORS_SHARED/)       | `@nexusdi/interceptors` | `InterceptorError`        | one `interceptors()` object was passed to a second container while another container still holds it; reported inside `NEXUS_BLUEPRINT_INVALID`, or the `cause` of `NEXUS_PROVIDER_FAILED` when two creates overlap                                                                           |
| [`NEXUS_INTERCEPTORS_UNCHECKED`](/errors/NEXUS_INTERCEPTORS_UNCHECKED/) | `@nexusdi/interceptors` | `InterceptorError`        | the plugin was asked to wrap an instance its compile never checked                                                                                                                                                                                                                           |
| [`NEXUS_OVERRIDE_UNUSED`](/errors/NEXUS_OVERRIDE_UNUSED/)               | `@nexusdi/testing`      | `OverrideError`           | a testing override names a token that no provider binds, or a module the graph never imports; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                         |
| [`NEXUS_OVERRIDE_EXPORTS`](/errors/NEXUS_OVERRIDE_EXPORTS/)             | `@nexusdi/testing`      | `OverrideError`           | a module stub does not export every token and module of the module it replaces; found inside `NEXUS_BLUEPRINT_INVALID`                                                                                                                                                                       |
