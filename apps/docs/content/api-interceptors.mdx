# `@nexusdi/interceptors`

An audit log or a timer runs around a service's methods, and the service's class carries none of that code. `@nexusdi/interceptors` wraps the instance the container builds. The `interceptors()` plugin registers interceptor classes and `interceptor()` entries, and wraps each class or factory instance that has interceptors. A class declares them with `static interceptors` or `@UseInterceptors()`, and a `bindings` entry names them for a token. A `global` entry applies them to every method, or to the methods its `when` filter accepts. An interceptor's `intercept(call, next)` runs around the method and calls `next()` to run the rest of the chain and the method.

`tap()` reports a call's outcome, sync or async. A sync call returns its own value, and an async call returns a new promise that settles the same way. An observer that throws replaces the outcome with its own error. A bad option fails `create()` with a `BlueprintError` whose `errors` list holds an `InterceptorError`, and a bad `@UseInterceptors()` throws one when the class is defined. `interceptorsText` from `@nexusdi/interceptors/text` words those errors for `@nexusdi/errors`. Each export has one entry below, with what the package's tests state about it.
