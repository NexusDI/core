# Lifetimes

A NexusDI lifetime decides how many instances a provider builds: one for the container, or a new one for every `get()`. A provider sets it with the `lifetime` option of `provide()`, next to `useClass` or `useFactory` (the forms from the previous page).

## NexusDI `singleton` and `transient` lifetimes

`singleton` is the default lifetime: the container builds the provider once, at `Nexus.create`, and every `get()` and every consumer receives that one instance. `lifetime: 'transient'` builds a new instance each time the container resolves the token, for every `get()` and for every consumer that depends on it. `QuantumComputer` below declares no lifetime, so it is a singleton. A third lifetime, `scoped`, builds one instance per scope, such as one per request. The Scopes and REQUEST page teaches it.

## Build a NexusDI singleton on first use with `eager: false`

`eager: false` on a singleton moves its build from `Nexus.create` to the first `get()` that asks for it, unless an eager provider depends on it, which builds it at `create` as before. ```

`get()` is synchronous, so a provider built at its first `get()` cannot wait for a promise. TypeScript rejects `eager: false` on an async factory with TS2769 on the `provide(` call, and the message of the last overload names the rule:

```ts fails-type-check
const charts = provide(NAV_CHARTS, {
  useFactory: async () => ({ plot: (target: string) => `course to ${target}` }),
  eager: false,
});
// TS2769: Type 'false' is not assignable to type 'true | "NEXUS_LAZY_ASYNC: an async
// provider is built during create or createScope, so it cannot be eager: false. ..." | undefined'
```

Try it: in the `eager: false` program, replace the `useClass` option with `useFactory: async () => new StarCharts()` and run `npx tsc`. TypeScript reports TS2769 on the `provide(` call, and the last overload's message holds the `NEXUS_LAZY_ASYNC` text above. Remove `async` and `npx tsc` reports nothing, and the program prints the same three lines as before. Dropping `eager: false` also clears the error.

A JavaScript factory that returns a promise at that first `get()` makes `get()` throw [`NEXUS_LAZY_ASYNC`](/errors/NEXUS_LAZY_ASYNC/). A transient factory must also return synchronously: a JavaScript one that returns a promise makes `get()` throw [`NEXUS_ASYNC_TRANSIENT`](/errors/NEXUS_ASYNC_TRANSIENT/), and TypeScript names that code when the factory is `async`.

Try it: run the `eager: false` program. It prints `[]`, then `course to Kepler-442b`, then `[ 'charts loaded' ]`. Delete `eager: false` and run it again. `beforeGet` now prints `[ 'charts loaded' ]`, because `Nexus.create` built the charts before the first `get()`. Put `eager: false` back and `beforeGet` prints `[]` again.
