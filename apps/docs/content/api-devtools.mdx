# `@nexusdi/devtools`

`@nexusdi/devtools` shows what a container holds and what it did while it started. `devtools()` is a development plugin that lets `graph(ship)` return the container's compiled graph as plain JSON. It hands every lifecycle event to the callback in its `trace` option, and it words errors with `@nexusdi/errors`. `inspect(root)` returns the same graph from the compiler alone, building nothing, for a CLI or a CI job, and `trace(fn)` is a plugin that only reports events. `toMermaid()` and `toDot()` draw a graph as a Mermaid flowchart or a Graphviz digraph, and `parseGraph()` reads a saved graph back and checks its shape. Each export has one entry below, with what the package's tests state about it.
