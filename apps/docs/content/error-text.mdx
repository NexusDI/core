# Error Text Packs

By default, NexusDI provides concise, one-line error messages. While efficient for developers, these can be too terse for some environments. **Text Packs** allow you to replace these codes with full, human-readable explanations and suggested fixes.

## How Text Packs Work

A text pack is a mapping of error codes to formatting functions. When the `@nexusdi/errors` plugin is registered, it reads these packs in order. The first pack that returns a message for a given code wins.

### Implementation Rules:
- **Type Safety:** Use the `satisfies ErrorTextPack` helper to ensure your pack matches the required error classes.
- **Fallbacks:** If your function returns `undefined`, NexusDI simply moves to the next pack in the list.
